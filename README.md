# Well Pump Generator Planner

A free, single-page tool that helps homeowners on well water size backup power for a well pump, furnace and fridge. It shows running watts, the start-up surge, a recommended generator rating, and a one-at-a-time start order.

- Static HTML/CSS/JS with no build step
- Default wattages are planning figures, and the page tells users to check their nameplates
- No affiliate links at the moment (see the disclosure on the page)

Not electrical advice. Have a licensed electrician connect any generator to home wiring.
